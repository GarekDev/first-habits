# First Habits

## Qué es

First Habits es la app de hábitos de First You, para Android. En el teléfono muestra lo que toca hoy, la racha, un recordatorio por hábito y un widget en la pantalla de inicio.

## Qué no hace

No tiene cuenta, no tiene servidor, no tiene anuncios, no tiene compras y no lee el correo.

## Cómo abrirla

En Android Studio: File, Open, y elige la carpeta de este repositorio. Hace falta el Android SDK 37 y un teléfono con Android 8 o mayor.

## Dónde están los datos

En el teléfono. Desde la app, en Copia de seguridad, se exportan a un archivo `first-habits-backup.json`. Ese archivo no entra en Git.
